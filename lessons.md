# Lessons: how to show a step so a second grader can follow it

Written after Jimmy's feedback on the Add & Subtract steps (round 6).

The steps failed because the words did not match what was on screen. "Break XC into LXXXX" ran the pieces together, so it looked like one thing. Nothing said that XC is 90, or that the pieces add up to 90. Every step needs the same basic things:

1. **Say what changes, to which part.** One change per step. "Take away L" names the letter and the side.
2. **Give the value, so the child can check.** "XC is 90. Write it as L + X + X + X + X." A value next to a change shows it is the same amount.
3. **Separate the pieces.** Use "+" between parts so "LXXXX" never reads as one word. Pieces are always spaced.
4. **Keep the whole sum visible, with the changed part marked.** The rest stays readable. The part that changed is highlighted, and an arrow shows what it became.
5. **Put the working on its own surface.** A bordered work window holds the sum. The caption sits outside it, so text and working do not blend.
6. **Use the same words everywhere.** "Take away", "trade", "same on both sides", "put together". Do not switch words between steps.
7. **Show the result of the step, not just the action.** Each step should leave the child able to see what is left.
8. **Test with real examples before shipping.** Read every caption in order, as a child would, and ask: could I explain this step to someone who has not seen it?
