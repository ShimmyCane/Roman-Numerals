Pictures to find

A planning page. Nothing here is shown on the other pages yet.

How this works

  1. Find each picture below. Save it with the exact file name, into a folder called assets in the repository (the folder for pictures).
  2. Only use pictures you are allowed to use: public domain, or a Creative Commons licence that allows reuse. Write the page where you found it and the licence in a file called assets/SOURCES.md.
  3. Avoid logos and trademarks, and do not use photos of children.
  4. Tell Claude when a folder is ready. Then the pictures are added to the pages where they belong, and the placeholders go in at the same time.

Any file name that does not fit can be changed, as long as the list above is updated too. Pictures are optional: each page still works without them.
